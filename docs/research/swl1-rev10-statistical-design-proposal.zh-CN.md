# SWL1 REV10 Short-V1 统计设计提案（成本锚定）

状态：**PROPOSAL_NOT_LOCKED**。正式状态仍为 `STATISTICAL_DESIGN_PENDING`，锁定需 owner 决定。
本提案不读取真实收益、探索聚合或任何绩效指标；最小效应量来自仓库既有执行成本，
**不由已看到的探索 RankIC 推出**。实现见[设计模块](../../research/swl1_rev10_short_v1/design.py)，
补充[正式研究草案](swl1-rev10-preregistration-draft.zh-CN.md)中“统计设计仍待确定”一节。

## 为什么需要成本锚

草案要求“独立锁定最小具有实际解释意义的效应量”，且不得据 +0.055633 反推。
与结果无关、又有实际意义的锚点是：信号的毛收益必须先覆盖交易成本。
探索报告中相邻 Top5 名单换手约 0.29，若每日调仓，成本可能超过毛收益差，
因此调仓规则必须与终点一起预先锁定。

## 提案内容

| 项目 | 提案 |
| --- | --- |
| 成本来源 | [既有执行配置](../../strategies/etf_quant_v2/config/release.json)：佣金 3bp、滑点 5bp、印花税 0bp（单边） |
| 调仓 | 自激活 session 起每 10 个交易日一次，非重叠 H10 持有 |
| 共同终点 | 每次调仓的 Top5−Bottom5 原始 H10 收益差扣除实际换手成本后的均值（净差） |
| 成本计算 | 每腿换掉的行业比例 × (卖出+买入单边成本)；首次调仓两腿全换 |
| 最小有意义效应 | 两腿全换的最坏成本：2 × (8+8)bp = **32bp / 每次调仓** |
| 精度目标 | 净差均值的 90% 单侧区间半宽 ≤ 32bp |
| 成功规则 | 固定终点时，净差均值 90% 单侧下界 > 0（与 H10 RankIC 主终点同时报告） |

H10 RankIC 仍是草案的主要终点；本提案只增加一个以成本为尺度的经济共同终点，
是否作为成功必要条件由 owner 决定。

## 样本量规划

非重叠周期数 n 满足 z·sd·√(VIF/n) ≤ 32bp，z=1.2816，每年约 24.2 个周期。
每期净差标准差 sd 与周期间依赖 VIF **必须来自与 REV10 结果无关的来源**
（例如随机 Top5−Bottom5 组合的离散度或外部文献），本提案不估计它们：

| 每期 sd | 所需周期（VIF=1） | 约合年数 |
| --- | ---: | ---: |
| 1% | 17 | 0.7 |
| 2% | 65 | 2.7 |
| 3% | 145 | 6.0 |
| 4% | 257 | 10.6 |

若每期 sd 超过约 1.7%，草案讨论的 24 个月（约 48 期）不足以达到此精度目标。
这应在任何前瞻观测前作为规划风险记录，而不是观测后再延长期限。

## 仍需 owner 决定

1. 是否采用 10 日非重叠调仓及上述成本假设（行业篮子实际成本可能高于 ETF）。
2. 净差是否作为成功必要条件，或仅为描述性共同终点。
3. sd 与 VIF 的独立来源及数值，以及据此锁定的停止日期。
